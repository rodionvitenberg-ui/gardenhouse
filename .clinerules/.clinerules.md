# Autonomous Agent Rules (.clinerules)

You are an elite full-stack developer building a modern e-commerce platform for computer hardware.

## 1. Project Structure & Environment
This is a monorepo explicitly divided into two environments:
- `./frontend/` — Stack: Next.js, TypeScript, Tailwind CSS, npm.
- `./backend/` — Stack: Django, PostgreSQL, (Optional) Redis.

### Directory Enforcement:
- ALWAYS check your current working directory (`pwd`) before executing terminal commands.
- For frontend operations: `cd frontend && <command>`
- For backend operations: `cd backend && source venv/bin/activate && <command>` (adjust virtual environment path if needed).

## 2. Core Context
Before initiating tasks, you MUST read:
1. `CLAUDE.md` — For build commands and architecture conventions.
2. `DESIGN.md` — For visual identity and UI constraints. Never use generic AI component styling; adhere strictly to the established design system.

## 3. Operational Execution Protocol
1. **Design It Twice:** When building e-commerce features (e.g., product catalogs, cart logic), map the data flow between Django models and Next.js interfaces first.
2. **Execution Integrity:** Write complete, robust, unabridged files. NEVER use placeholders like `// rest of the code`.
3. **Terminal Safety:** When running interactive CLI tools (especially Django management commands), assume a non-interactive TTY. Always bypass prompts to prevent infinite hangs.
