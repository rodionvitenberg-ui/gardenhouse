# Father's Garden — Глоссарий предметной области

## Основные понятия

| Термин | Определение |
|--------|------------|
| **Father's Garden** | Единое поместье, объединяющее питомник многолетних растений и один гостевой дом. Не сеть объектов, а одно конкретное место. |
| **Guest House** (Гостевой дом) | Единственный дом на территории поместья, доступный для бронирования. Вмещает ограниченное количество гостей. Бронирование происходит через заявку, а не мгновенное подтверждение. |
| **Nursery** (Питомник) | Питомник многолетних растений, деревьев, кустарников и семян. Физически расположен на территории Father's Garden. |
| **Shop** (Магазин) | Онлайн-витрина товаров питомника. Каталог имеет иерархию: Категория → Товар. |
| **Category** (Категория) | Группа товаров питомника: многолетники, деревья и кустарники, семена. |
| **Product** (Товар) | Конкретное растение или товар питомника с ценой, наличием и статусом доступности. |
| **Journal** (Журнал) | Редакционный блог: заметки садовода, сезонные советы, истории гостей. |
| **Booking Request** (Заявка на бронирование) | Запрос от гостя на проживание в гостером доме в определённые даты. Требует подтверждения владельцем — не является мгновенным бронированием. |

## Роли

| Термин | Определение |
|--------|------------|
| **Guest** (Гость) | Посетитель сайта, который может просматривать товары, делать заказ или бронировать дом. |
| **Owner** (Владелец) | Управляющий поместьем — подтверждает заявки на бронирование, управляет каталогом через админ-панель Django. |

## Состояния и процессы

| Термин | Определение |
|--------|------------|
| **Availability** (Доступность товара) | `AVAILABLE` — в наличии, `PREORDER` — предзаказ (ожидается сезон), `OUT_OF_STOCK` — закончилось. |
| **Booking Status** (Статус бронирования) | `PENDING` — новая заявка (ожидает решения), `CONFIRMED` — подтверждено, `CANCELED` — отклонено. |
| **Locale** (Язык) | Поддерживаются русский (`ru`) и английский (`en`). По умолчанию определяется по языку устройства посетителя. |
